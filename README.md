# The Experts Group — website

Standalone React + Vite + Tailwind build of the TEG homepage.

## Run it

```
npm install
npm run dev
```

Then open http://localhost:5174

## Notes

- All media lives in `public/media/` (photos + films). `public/teg-logo.png` is the transparent group logo.
- Every route currently renders the homepage; brand pages come later.
- Accent words use EB Garamond italic (`.font-script` in `src/index.css`); polaroid captions use Caveat.
